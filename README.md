CyberSecurity-Awareness-Bot
Project Description: This project is an interactive application, and it has been created using C#. The application has been created to fulfil the requirements of education, and the basic concepts related to cybersecurity can be understood by the user. It is a simple and interactive application developed to serve the purpose of providing a desktop application where the beginner can learn about different types of cybersecurity threats.
System Setup (For Beginners)
To execute the application locally, do these steps using Visual Studio: -
1.	Open Visual Studio 
•	Clone Project 
•	On the start window, click Clone a repository.
•	Paste the GitHub URL provided for this project in the Repository location box.
•	Specify a folder to clone the project and click Clone.
2.	Open the Solution:
•	After the project has cloned, go to Solution Explorer, which is normally located at the right end of the screen.
•	Double-click the file CyberSecurity-Awareness-Bot.slnx.
3.	Run the Application:
•	Locate the green button with the label "Start," which should be located at the top of the screen and have the label CyberSecurity-Awareness-Bot.
•	Click the button or press F5 on your keyboard.
•	The chatbot window should pop up once the build is complete. (Gemini, 2025)
Usage Instructions
To use the bot after it has been initialized you may enter or copy and paste the commands below into chat to test the bot: 
•	For learning about email safety: Copy and paste the text "Explain Phishing"
•	For learning about password strength: Copy and paste the text "How do I make a strong password?"
•	For learning about security: Copy and paste the text "Show me security tips" (Gemini, 2025)
Project Functionalities & Status
Current Features
1.	Direct Chat Interface: The project has a simple desktop window for user interaction.
2.	Security Library: The library includes pre-defined responses for the most common cyber threats faced by a user.
3.	Automated Verification: The project is integrated with GitHub Actions for automated build verification. (Gemini, 2025)
Current Stage
The current phase of the project is MVP (Minimum Viable Product), and at this point all of the bot logic and UI are functioning normally. (Gemini, 2025)
Future Advancements
•	Live Database: Moving from pre-defined responses to a live security database API.
•	User Progress Tracking: Saving a history of what the user has learned.
•	Interactive Quizzes: Adding the "Test Your Knowledge" mode. (Gemini, 2025)
Troubleshooting & Fixes
The problem encountered during development was when Visual Studio failed to redirect to authorize my GitHub account. To resolve this, I initialized a new repository using the Git Terminal, committed my files, and pushed them to the main branch. I also modified the GitHub Actions workflow to identify the format of the solution file for this solution. (Gemini, 2025)
